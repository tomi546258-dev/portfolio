Corner-Corrected Integral (CCI) —
Kvantált jelekre optimalizált numerikus integrátor

Bódis Tamás · ORCID 0009-0004-6349-712X · Óbudai Egyetem, KVK · Saját munkaanyag
Összefoglalás
A Corner-Corrected Integral (CCI) egy egyszerű, egész-aritmetikán alapuló numerikus integrálási módszer, amely a klasszikus téglalap-szabályt egy kvadratikus sarokkorrekciós taggal egészíti ki. A korrekció egy geometriai azonosságból fakad: $(n-1)(n+1) = n^2 - 1$, amelynek átlaga $n^2 - \tfrac{1}{2}$. A cél nem egy magasabb rendű kvadratúra, hanem egy olcsó korrekció lépcsős (kvantált) jelekre: a korrekciós tag minden szintváltásnál a lépcső fél mintányi területét pótolja, csak egész szorzással és összeadással, $O(1)$ memóriával, lebegőpontos egység nélkül.

Korlátok, amiket érdemes tudni: a korrekció $n^2$-es, ezért a módszer nem lineáris a jelben ($I(2y) \neq 2I(y)$), és az $n$ paraméter hangolást igényel — rosszul megválasztott $n$-nel a hiba nagyobb, mint a sima téglalap-szabályé. Az összehasonlító mérés újrafuttatása folyamatban van; addig a módszer kísérleti munkaanyagnak tekintendő.

Lakásablakok ihletése
Az alaptétel egy lakótömb ablakrácsának megfigyeléséből ered: egy $n\times n$ négyzetből $(n-1)\times(n+1)$ téglalapba lépve az area pontosan 1-gyel csökken. Az átlag adja a $-\tfrac{1}{2}$ korrekciót.
Pontosság
Egész aritmetika, FPU nélkül
A számítás egész szorzásból és összeadásból áll, mintánként konstans munkával és $O(1)$ memóriával — 8 bites mikrovezérlőn is elfut.
Automatikus n-hangolás
Skála/fázis-invariancia
Az $n$ korrekciós paramétert decimálással és félmintás eltolással határozza meg az algoritmus — ground truth nélkül, $O(N)$ időben, $O(1)$ memóriával.

Alapegyenletek
Geometriai identitás — a korrekció eredete
$$(n-1)(n+1) = n^2 - 1, \qquad \frac{n^2 + (n^2-1)}{2} = n^2 - \frac{1}{2}$$
Sarokindikátor és sarokszám
$$\delta_k = \begin{cases} 1, & k=1 \\ 1, & k\ge 2 \text{ és } y[k]\neq y[k-1] \\ 0, & \text{egyébként} \end{cases}, \qquad K(y) = \sum_{k=1}^N \delta_k$$
A CCI-formula
$$I_\text{CCI} = \sum_{k=1}^N y[k]\,\Delta t \;+\; K(y)\cdot\Delta t\cdot\!\left(n^2 - \frac{1}{2}\right)$$
∑ y[k]·Δt  — téglalap-összeg $I_\text{rect}$
K(y)·Δt·(n²−½)  — sarokkorrekció
Automatikus n-hangolás — skálainvariancia-egyenlet
$$m^{(s,p)} = \frac{1}{2} + \frac{I_\text{rect}^{(s,p)} - I_\text{rect}^f}{\Delta t\,(K_f - s\,K_c)}, \qquad n^\star = \sqrt{\operatorname{clip}(m^\star;\,0,1)}$$
Globális hibakorlát
$$I_\text{CCI} - I_\text{rect} = K(y)\,\Delta t\left(n^2 - \tfrac{1}{2}\right) \qquad\text{— a korrekció a szintváltások számával skálázódik, nem $h$ rendjével}$$

Implementáció — pszeudokód
Mikrovezérlő (8-bit, egész aritmetika)
/* y[]   : kvantált minták (LSB)
 * n_q   : hangolt korrekciós paraméter, 2^8-as fixpontban (0…256)
 * dt_q  : mintavételi idő fixpontban
 * Az akkumulátor 32 bites: 8 bites mintáknál is túlcsordul a 16 bites. */

int32_t  acc  = 0;          // téglalap-összeg
uint16_t K    = 1;          // szintváltások száma (az első sarok is az)
uint8_t  prev = y[0];

for (uint16_t i = 0; i < N; i++) {      // N > 255 miatt uint16_t!
    acc += (int32_t)y[i];
    if (i > 0 && y[i] != prev) { K++; prev = y[i]; }
}

/* korrekció: K * dt * (n^2 - 1/2), fixpontban.
   A -1/2-et 256-os skálán 128 képviseli. */
int32_t corr = ((int32_t)K * ((int32_t)n_q * n_q / 256 - 128)) / 256;

int32_t I_CCI = (acc + corr) * dt_q;
MATLAB — kompakt verzió
function I = cci_integrate(y, dt, n)
    if nargin < 3
        error('cci_integrate:n', 'Az n korrekciós paramétert meg kell adni (0..1).');
    end
    n = min(max(n, 0), 1);   % a korrekció csak ebben a tartományban értelmes
    y = y(:); N = numel(y);
    I_rect = sum(y) * dt;
    tol = max(1e-12, 1e-6*(max(y)-min(y)+eps));
    K = 1 + sum(abs(diff(y)) > tol);
    I = I_rect + K * dt * (n^2 - 0.5);
end
Hibakorlát
Maximális hiba szegmensenként
Egyetlen szintváltásnál a korrekció a $\left(n^2-\tfrac{1}{2}\right)\Delta t$ tagot adja hozzá, miközben a valódi lépcsőterület a szintváltás helyzetétől ($\delta \in [0,1)$) függ. Az eltérés szegmensenként korlátos, de nem egyenletesen kicsi: rögzített $n$ mellett a korrekció alulbecsülheti és túl is lőheti a valódi területet, és a hiba a jel amplitúdójával együtt nő, mert a korrekciós tag $n$-ben kvadratikus. Ezért a módszer gyakorlati használatához az $n$ paramétert hangolni kell (lásd az automatikus $n$-hangolást), és az eredményt mindig érdemes trapéz-szabállyal ellenőrizni.
