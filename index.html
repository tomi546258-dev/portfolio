Corner-Corrected Integral (CCI) —
Kvantált jelekre optimalizált numerikus integrátor

Bódis Tamás · ORCID 0009-0004-6349-712X · Óbudai Egyetem, KVK · MDPI Electronics / Sensors
Összefoglalás
A Corner-Corrected Integral (CCI) egy egyszerű, egész-aritmetikán alapuló numerikus integrálási módszer, amely a klasszikus téglalap-szabályt egy kvadratikus sarokkorrekciós taggal egészíti ki. A korrekció egy geometriai azonosságból fakad: $(n-1)(n+1) = n^2 - 1$, amelynek átlaga $n^2 - \tfrac{1}{2}$. Az eredmény $O(h^3)$ globális hibakorlát — egy renddel jobb a téglalap- és trapézszabálynál lépcsős jeleknél. Szintetikus teszteken (szinusz, PWM, kvantált Gauss) a CCI az RMS hibát 30–60%-kal csökkenti a klasszikus szabályokhoz képest, és 15%-kal jobb Simpson-módszernél is — miközben lebegőpontos egység nélkül, $O(1)$ memóriával futtatható mikrovezérlőkön.

Lakásablakok ihletése
Az alaptétel egy lakótömb ablakrácsának megfigyeléséből ered: egy $n\times n$ négyzetből $(n-1)\times(n+1)$ téglalapba lépve az area pontosan 1-gyel csökken. Az átlag adja a $-\tfrac{1}{2}$ korrekciót.

Alapegyenletek
Geometriai identitás — a korrekció eredete
$$(n-1)(n+1) = n^2 - 1, \qquad \frac{n^2 + (n^2-1)}{2} = n^2 - \frac{1}{2}$$
Sarokindikátor és sarokszám
$$\delta_k = \begin{cases} 1, & k=1 \\ 1, & k\ge 2 \text{ és } y[k]\neq y[k-1] \\ 0, & \text{egyébként} \end{cases}, \qquad K(y) = \sum_{k=1}^N \delta_k$$
A CCI-formula
$$I_\text{CCI} = \sum_{k=1}^N y[k]\,\Delta t \;+\; K(y)\cdot\Delta t\cdot\!\left(n^2 - \frac{1}{2}\right)$$
∑ y[k]·Δt  — téglalap-összeg $I_\text{rect}$
K(y)·Δt·(n²−½)  — sarokkorrekció
Automatikus n-hangolás — skálainvariancia-egyenlet
$$m^{(s,p)} = \frac{1}{2} + \frac{I_\text{rect}^{(s,p)} - I_\text{rect}^f}{\Delta t\,(K_f - s\,K_c)}, \qquad n^\star = \sqrt{\operatorname{clip}(m^\star;\,0,1)}$$
Globális hibakorlát
$$E_\text{CCI} = O(h^3) \quad\text{lépcsős jelek esetén} \qquad \text{vs.}\qquad E_\text{rect} = O(h^2), \quad E_\text{trap} = O(h^2)$$

Implementáció — pszeudokód
Mikrovezérlő (8-bit, egész aritmetika)
uint16_t sum = 0;
uint8_t prev = sample[0];
sum += (prev * prev * 2 - 1) / 2;   // első sarok

for (uint8_t i = 1; i < N; i++) {
    uint8_t n = sample[i];
    sum += n * dt;                   // téglalap tag
    if (n != prev) {
        sum += (n*n*2 - 1) / 2;     // sarokkorrekció
        prev = n;
    }
}
// I_CCI = sum
MATLAB — kompakt verzió
function I = cci_integrate(y, dt, n)
    if nargin < 3, n = mean(y)/2; end
    y = y(:); N = numel(y);
    I_rect = sum(y) * dt;
    tol = max(1e-12, 1e-6*(max(y)-min(y)+eps));
    K = 1 + sum(abs(diff(y)) > tol);
    I = I_rect + K * dt * (n^2 - 0.5);
end
Hibakorlát
Maximális hiba szegmensenként
Legyen $f(x) = n + \delta$, ahol $\delta \in [0,1)$ a kvantálási maradék. A CCI becslés: $n^2 - \tfrac{1}{2}$. A valódi érték $(n+\delta)^2 = n^2 + 2n\delta + \delta^2$. A hiba tehát: $E = 2n\delta + \delta^2 + \tfrac{1}{2}$, maximuma ($\delta \to 1$): $E_\max = 2n + 1.5$. A CCI mindig kissé felülbecsli az integrált, de konzisztensen közelebb marad az igaz értékhez, mint a téglalap-szabály.
