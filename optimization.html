Optimumszámítás a hétköznapokban

Közös minta
Első ránézésre a bojler, a villanykörte, az erősítő és az étterem teljesen különböző problémák. Mégis mind ugyanolyan szerkezetű kérdést tesznek fel: meddig érdemes menni? Mikor kezd el több kárt okozni valami, mint hasznot?
HÉTKÖZNAPI INTUÍCIÓ
Ha egy napig sem járok haza, felesleges a bojler — de ha két hetet leszek távol, már nagyon megéri lekapcsolni. Valahol a kettő között van az optimum.
MATEMATIKAI SZERKEZET
Minden ilyen problémában van egy nyereség (amit maximalizálunk) és egy költség (amit minimalizálunk). Az optimum ott van, ahol a kettő határon egyensúlyban van.
A λ (lambda) paraméter azt fejezi ki, hogy számodra mennyit ér az egyik szempont a másikhoz képest. Ha az étteremben a vendégek élményét fontosabbnak tartod a bevételnél, nagy λ-t választasz — és az optimális telítettség alacsonyabb lesz. Ha a bevétel az elsődleges, kis λ-val dolgozol — és zsúfoltabb éttermet tolerálsz. Nincs egyetlen helyes λ — ez értékítélet.
Formálisan minden probléma leírható így: max(nyereség − λ · költség). Az optimum feltétele: a két hatás deriváltja egyenlő — vagyis a marginálisnál (a következő kis lépésnél) a nyereség és a költség éppen egyforma mértékben változik. Ha a nyereség gyorsabban nő, érdemes továbblépni. Ha a költség nő gyorsabban, vissza kell lépni.
Általános alak
$$\max_{x}$$
[
$\text{Gain}(x)$
nyereség
$\;-\;\lambda\;\cdot\;$
$\text{Cost}(x)$
költség
]
$\;\Longrightarrow\;$
$$\frac{d(\text{Gain})}{dx} = \lambda\cdot\frac{d(\text{Cost})}{dx}$$
Bojler: nyereség = megtakarított energia, költség = újramelegítés  ·  Izzó: nyereség = spórolt áram, költség = rövidebb élettartam
Erősítő: nyereség = erősítés (Av), költség = torzítás (THD)  ·  Étterem: nyereség = bevétel, költség = vendégelégedetlenség
Interaktív problémák
Lakásban villanybojler napi 3 órát fűt. Ha ritkán járunk be, érdemes lekapcsolni — de az újraforrósítás egyszeri költség. Mikortól éri meg?
Megtérülési feltétel
$P \cdot t_{\text{heat}} \cdot c \cdot N$
napi cost × N nap
$\;\geq\;$
$P \cdot t_{\text{reheat}} \cdot c$
újramelegítés (egyszeri)
$\;\Rightarrow\;$
$$N^* = \dfrac{t_{\text{reheat}}}{t_{\text{heat}}}$$
ℹ︎ N* = t_reheat / t_heat — független P-től és c-től (kiesnek az egyenletből)
⟶ Eredmény itt jelenik meg

A probléma diszkrét esemény + folytonos költség típusú. A "kapcsolás" egy Dirac-delta jellegű egyszeri költség, míg a napi fűtés folytonos.

$$J(N) = N\cdot P\cdot t_h\cdot c - P\cdot t_r\cdot c \;\;\Rightarrow\;\; J(N^*)=0 \;\;\Rightarrow\;\; N^* = \frac{t_r}{t_h}$$

Ez nem funkcionál-variáció, hanem egyszerű törésponti egyenlet. Az optimum ott van, ahol a kumulatív megtakarítás éppen fedezi az újramelegítési költséget. Nincs szükség deriváltra — a függvény lineáris $N$-ben.

Egy bekapcsolás az izzó élettartamát csökkenti. Az energiaköltség idő szerint folytonos. Az optimum az az idő, ahol a két költség egyenlő.
Optimális kikapcsolási idő
$$t^* = \frac{C_{switch}}{P \cdot c_{kWh}} = \frac{C_{bulb}/L_{hours}}{P \cdot c_{kWh}}$$
⟶ Eredmény itt jelenik meg

A célfüggvény minimalizálja az összes "élettartam-egységnyi" költséget:

$$C_{total}(t) = \underbrace{P\cdot c \cdot t}_{\text{energiaköltség}} + \underbrace{\frac{C_{bulb}}{L}}_{\text{kapcsolási élettartam-veszteség}}$$

A $t^*$ az az időküszöb, ahol a fenn tartás marginális energiaköltsége eléri a kapcsolás marginális élettartam-veszteségét. Ez a határ-elvű optimum legegyszerűbb formája.

$$\frac{dC_{energy}}{dt} = P\cdot c \;\;\geq\;\; \frac{C_{bulb}}{L} = C_{switch} \quad\Rightarrow\quad t \;\geq\; t^*$$
Földelt emitteres erősítőnél a kollektorellenállás növelése javítja az erősítést, de rontja a linearitást. Az optimum a Pareto-határon van: max erősítés adott THD-küszöb mellett.
Célfüggvény
$$J(R_C, R_E) = \log(A_v) - \lambda\cdot\text{THD}(R_C,R_E) \quad\Rightarrow\quad \nabla J = 0$$
⟶ Eredmény itt jelenik meg

Az erősítőoptimum kétdimenziós: a $(R_C, R_E)$ tér felett kell maximumot keresni. Ez már valódi multivariábilis optimum, ahol a gradiens feltétel:

$$\frac{\partial J}{\partial R_C} = \frac{1}{A_v}\frac{\partial A_v}{\partial R_C} - \lambda\frac{\partial\text{THD}}{\partial R_C} = 0$$

A Pareto-front megmutatja az összes kompromisszumot: minden λ értékhez más optimális pont tartozik. Az "igazi" optimum a Pareto-határon van, ahol nincs javítás az egyik szempontból a másik rontása nélkül.

Motoros potméterrel ez egy black-box optimumkeresés: nem ismerjük a függvény analitikus alakját, csak mérjük. Ekkor koordináta-descent vagy Nelder–Mead módszer alkalmazható.

Sorbanállás-elmélet: az étterem telítettsége (ρ) és a bevétel/élmény kompromisszuma. Telítettség közelében a várakozási idő nemlineárisan robban — ez a M/M/1 sor viselkedése.
M/M/1 várakozási idő
$$W = \frac{1}{\mu - \lambda} = \frac{1}{\mu(1-\rho)}, \quad \rho = \frac{\lambda}{\mu} < 1$$
⟶ Eredmény itt jelenik meg

A M/M/1 sor optimuma az a ρ*, ahol a bevétel és az elveszett vendégek (rossz értékelések) miatti veszteség kompenzálják egymást:

$$J(\rho) = R\cdot\rho - \lambda\cdot W(\rho) = R\cdot\rho - \frac{\lambda}{\mu(1-\rho)}$$
$$\frac{dJ}{d\rho} = R - \frac{\lambda}{\mu(1-\rho)^2} = 0 \quad\Rightarrow\quad \rho^* = 1 - \sqrt{\frac{\lambda}{\mu R}}$$

Vegyük észre: a $\rho \to 1$ határnál $W \to \infty$ — a rendszer "szétesik". Ez a variációszámításban az egyensúly elvesztése: a funkcionál nem korlátozott felülről ρ=1 közelében.

Matematikai alap
Az összes fenti probléma egy közös matematikai sémából ered. Az optimum feltétele mindig a célfüggvény deriváltjának eltűnése — de ez a derivált sokféle formát ölthet: hely szerinti, funkcionál szerinti, vagy mező szerinti.
1. szint — Szám → szám optimum
$$\frac{dJ(x)}{dx} = 0 \quad\Rightarrow\quad x^*$$
2. szint — Funkcionál optimum (variáció)
$$J[u] = \int_\Omega L(x, u, u')\,dx,\qquad \delta J = \frac{d}{d\varepsilon}\bigg|_{\varepsilon=0} J[u+\varepsilon\eta] = 0 \;\;\forall\eta$$

A variáció a funkcionál Gâteaux-deriváltja: nem egy számon, hanem egy teljes függvényen értelmezett derivált.

$$\delta J[u;\eta] = \lim_{\varepsilon\to 0}\frac{J[u+\varepsilon\eta]-J[u]}{\varepsilon} = \int_\Omega \left(\frac{\partial L}{\partial u}\eta + \frac{\partial L}{\partial u'}\eta'\right)dx$$

Részleges integrálással (ha $\eta$ az elemen eltűnik):

$$\delta J = \int_\Omega \underbrace{\left(\frac{\partial L}{\partial u} - \frac{d}{dx}\frac{\partial L}{\partial u'}\right)}_{\text{Euler–Lagrange maradék}} \eta\,dx = 0 \;\;\forall\eta$$

Ha ez minden $\eta$-ra nulla, akkor a maradék maga is nulla — ez az Euler–Lagrange-egyenlet:

$$\frac{\partial L}{\partial u} - \frac{d}{dx}\frac{\partial L}{\partial u'} = 0$$

Fontos: ez az erős alak. A gyenge alak maga a variációs feltétel — és ez alapja a végeselem módszernek.

A hierarchikus eset: ha a Lagrange-sűrűség maga is egy másik funkcionál variációs deriváltjára épül:

$$F[u] = \int_\Omega \Psi\!\left(\frac{\delta J[u]}{\delta u}\right)dx \quad\Rightarrow\quad \delta F = 0 \;\Rightarrow\; \nabla^4 u = 0\;\text{ (biharmonikus)}$$

Bojler / izzó — analitikus optimum
def boiler_optimum(P_kW, t_heat_h, t_reheat_h, c_HUF_per_kWh):
    """Hány nap után érdemes lekapcsolni a bojlert?"""
    daily_cost = P_kW * t_heat_h * c_HUF_per_kWh      # Ft/nap
    reheat_cost = P_kW * t_reheat_h * c_HUF_per_kWh   # Ft (egyszeri)
    N_star = reheat_cost / daily_cost
    return N_star

def bulb_optimum(P_W, c_HUF_per_kWh, bulb_price_HUF, lifetime_h):
    """Hány másodperc után éri meg lekapcsolni az izzót?"""
    C_switch = bulb_price_HUF / lifetime_h          # Ft / kapcsolás
    P_kW = P_W / 1000
    t_star_h = C_switch / (P_kW * c_HUF_per_kWh)
    return t_star_h * 3600  # másodpercben

print(boiler_optimum(1.5, 3, 5, 30))  # → 1.67 nap
print(bulb_optimum(100, 50, 500, 10000))  # → 36 mp
Erősítő — koordináta-descent (black-box)
import numpy as np

def measure_gain_thd(RC, RE):
    """Szimulált mérés: erősítés és torzítás."""
    Av = RC / (RE + 26)           # közelítő, 26Ω = rE @ 1mA
    THD = 0.01 * (RC / 1000)**2 / (RE + 1)**0.5  # nemlineáris modell
    return Av, THD

def J(RC, RE, lam=10):
    Av, THD = measure_gain_thd(RC, RE)
    if THD > 0.05:  # 5% THD küszöb
        return -1e6  # bünteti a túl nagy torzítást
    return np.log(Av) - lam * THD

# Koordináta-descent
RC, RE = 4700, 47   # Ohm
step = 200
for iteration in range(50):
    for direction, param in [(1, 'RC'), (-1, 'RE')]:
        for delta in [step, -step]:
            if param == 'RC':
                new_J = J(RC + delta, RE)
                if new_J > J(RC, RE):
                    RC += delta
            else:
                new_J = J(RC, RE + delta)
                if new_J > J(RC, RE):
                    RE += delta
    step *= 0.9   # csökkentjük a lépésközt

print(f"Optimum: RC={RC}Ω, RE={RE}Ω")
Av_opt, THD_opt = measure_gain_thd(RC, RE)
print(f"Av={Av_opt:.1f}x, THD={THD_opt*100:.2f}%")
Étterem — M/M/1 analitikus optimum
import numpy as np

def restaurant_optimum(mu, R_per_guest, lambda_cost):
    """
    mu: kiszolgálási ráta (vendég/óra)
    R_per_guest: bevétel/vendég (Ft)
    lambda_cost: élménysúly (Ft·óra)
    """
    rho_star = 1 - np.sqrt(lambda_cost / (mu * R_per_guest))
    rho_star = np.clip(rho_star, 0, 0.99)
    W_star = 1 / (mu * (1 - rho_star))     # várakozási idő (óra)
    J_star = R_per_guest * rho_star - lambda_cost * W_star
    return rho_star, W_star * 60, J_star   # perc

# Példa: étterem 20 vendég/óra kapacitással
rho, W_min, profit = restaurant_optimum(
    mu=20, R_per_guest=3500, lambda_cost=8000
)
print(f"Optimális telítettség: {rho*100:.1f}%")
print(f"Várakozási idő: {W_min:.1f} perc")
print(f"Profit-score: {profit:.0f}")
Általános black-box optimum — Nelder–Mead (scipy)
from scipy.optimize import minimize
import numpy as np

def black_box_objective(params):
    """Cseréld le saját mérési függvényedre."""
    x, y = params
    # Szimulált célfüggvény: max gain, min torzítás
    gain = -np.log(abs(x) + 1) - 0.5 * np.log(abs(y) + 1)
    thd  = 0.01 * x**2 / (y + 1)**0.5
    return gain + 10 * thd   # minimalizálandó

result = minimize(
    black_box_objective,
    x0=[4700, 47],
    method='Nelder-Mead',
    options={'xatol': 1, 'fatol': 0.001, 'maxiter': 500}
)
print(f"Optimum: {result.x}")
print(f"Iterációk: {result.nit}")
